# Licensing decision before public release

A redistribution or open-source license has **not** yet been selected for this demonstration project. The author retains copyright. The project can be reviewed privately and prepared for a public portfolio repository; public GitHub visibility does not by itself authorize copying, redistribution, or commercial use.

Before publishing, choose a deliberate strategy:

- **Portfolio only, rights reserved:** leave without a permissive license. Visitors can inspect source but do not receive broad reuse rights.
- **MIT / Apache 2.0:** use a standard open-source license for the *demo code*, accepting that anyone may reuse the code under its terms.
- **Commercially differentiated product:** keep paid connectors, customer integrations, advanced reporting, and enterprise deployment functionality in separate private repositories, whatever license is selected for this demo.

No employer or client data belongs in any version published to GitHub.
